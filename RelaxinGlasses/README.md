# RelaxinGlasses

Vídeos con IA (UGC) para **RelaxinGlasses**: gafas LED de luz roja para ojeras. Montura blanca que se apoya **debajo de los ojos** (los ojos quedan libres por encima), dos almohadillas con placas plateadas, patillas flexibles y botones "Mode" y "+/-" en el lado izquierdo.

Misma forma de trabajar que el equipo de Aleix (ver `../referencia-aleix/`).

```
aprendizajes/        ← LEER ANTES DE GENERAR
  lecciones.md               lecciones propias de RelaxinGlasses
  prompts-que-funcionan.md   plantillas probadas con este producto
  registro-generaciones.md   cada generación: modelo, coste, resultado, lección
productos/
  kit/          fotos limpias (fondo gris) para usar como referencia: frente_apagado, encendido, interior
  recortes/     recortes de fotos de AliExpress (solo producto)
  originales/   fotos originales de AliExpress usadas para el kit
avatares/mujer47/   avatar mujer ~47 años: solo_cara (sin ojeras), cara_ojeras (con ojeras)
fondos/             comedor, sofá beige
proyectos/          un vídeo = una carpeta: AAAA-MM-DD_arnau_nombre
    referencia/  trozos/  generaciones/  final/
```

**No subir aquí fotos de personas reales** (repo público). Las fotos del producto puesto en clientas reales están solo en el ordenador de Arnau y se suben con `upload_image` de APIMart.

Descargas automáticas: `../sistema/pedidos/` (ver README principal).
